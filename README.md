# NAVABHARATH TECHNOLOGIES — Corporate Web Platform

A professional, modern, premium, and fully responsive corporate website engineered for **NAVABHARATH TECHNOLOGIES** using React JS, HTML5, CSS3, JavaScript, React Router DOM, Framer Motion, and Lucide React.

## 🎨 Color Palette & Brand Identity
- **Yellow / Gold:** `#FFC928` (Primary brand accent, CTAs, highlight badges)
- **Dark Navy Blue:** `#071B3A` (Primary background, deep corporate contrast)
- **Dark Surfaces & Cards:** `#0A234A` / `#0E2D5E`
- **White / Light:** `#FFFFFF` / `#F8FAFC`
- **Official Logo:** Uses the company's authentic, unmodified shield emblem and typography.

## 🌐 Connected Pages (7 Dedicated Routes)

1. **Home (`/`)**
   - Animated Hero section with headline: **"Smarter Solutions for Better Future"**
   - Company introduction, quick CTAs ("Explore Services", "Request a Quote", "View Case Studies")
   - Floating technology visuals and badges
   - Dynamic Highlights bar with animated metrics counters
   - Core Services preview cards with interactive detail modal
   - Featured Projects gallery with case study modals
   - "Why Navabharath" value pillars
   - Executive client testimonials
   - Conversion-focused bottom CTA banner
   - Modern corporate footer

2. **About Us (`/about`)**
   - Comprehensive company profile and executive background
   - Mission, Vision, and Core Values (Architectural Excellence, Radical Transparency, Client-Centric Agility, Relentless Innovation)
   - Interactive corporate journey and growth timeline (2020 – 2026)
   - Executive Leadership team cards with designations, bios, and LinkedIn profiles
   - Animated statistics counters
   - Corporate identity showcase and verified credentials

3. **Services (`/services`)**
   - 7 Specialized Services in animated cards:
     1. **Web Development**
     2. **Software Development**
     3. **Mobile App Development**
     4. **UI/UX Design**
     5. **Digital Solutions**
     6. **IT Consulting**
     7. **Software Testing & QA**
   - Each card features: Iconography, Deliverables checklist, Tech stack tags, "Full Specs" modal drawer, and direct "Inquire Now" routing with pre-selected service on the Contact page.
   - Six-stage Software Delivery Framework (Discovery, UI/UX, Agile Sprints, Automated QA, Deployment, Support).

4. **Portfolio (`/portfolio`)**
   - Comprehensive project gallery across Web, Software, Mobile Apps, UI/UX, and Digital Solutions.
   - Live category filter tabs.
   - Rich project cards with domain tags, metrics, and technology badges.
   - Interactive **Case Study Modal** showing Executive Summary, Technical Challenge, Engineering Solution, Measurable Outcomes, and Frameworks.

5. **Resources (`/resources`)**
   - Articles, tutorials, whitepapers, and industry insights.
   - Real-time search filter and category pills.
   - Interactive **Article Reader Modal** with full article content, key takeaways, and share button.
   - Downloadable Technical Whitepapers simulation with instant feedback toast.
   - Newsletter subscription banner with email validation.

6. **Careers (`/careers`)**
   - Company culture and employee perks (High-Impact Innovation, Hybrid Culture, Continuous Growth, Health & Wellness, Competitive Rewards).
   - Active job openings across Engineering, Cloud, Mobile, UI/UX, and QA.
   - Job Specifications modal detailing responsibilities, candidate requirements, and perks.
   - Validated **Resume Submission Modal** with full candidate details, experience level, document attachment picker (.pdf, .doc), progress bar, and submission feedback.

7. **Contact Us (`/contact`)**
   - Validated contact & consultation form (Name, Corporate Email, Phone, Service selection, Budget tier, Project scope).
   - Real-time feedback with loading spinner, toast notifications, and success confirmation screen.
   - Corporate Headquarters contact details with clearly designated editable placeholders for missing official records (`[Editable Placeholder]`).
   - Interactive stylized dark mode visual map placeholder with coordinates and direct link.
   - Social channel links (LinkedIn, Twitter, GitHub, Instagram) with hover animations.

## ⚡ Technical Architecture & UX Features

- **Sticky Glassmorphism Navbar:** Blur backdrop with brand logo, active route indicator, responsive mobile slide-out drawer.
- **Smooth Page Transitions:** Seamless enter/exit animations via Framer Motion `AnimatePresence`.
- **Animated Counters:** Numbers count up smoothly when scrolled into view.
- **Scroll Management:** Automatically resets scroll position on route transitions and provides a floating "Back to Top" button.
- **Initial Brand Preloader:** Smooth loading screen with logo pulse and progress indicator.
- **Notification System:** Global toast notifications for all user interactions (form submissions, downloads, copy actions).
- **Zero Dead Ends:** Every link, button, filter, tab, and modal is functional.
- **Clean Folder Structure:** Reusable modular components, centralized data models, and standard naming conventions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended; built and tested on v26)
- npm or pnpm

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
